# 📊 SQL Data Warehouse Analytics Project

An end-to-end SQL Data Warehouse and Analytics project built using MySQL.  
This project demonstrates data exploration, business analysis, customer insights, and product analytics using advanced SQL techniques.

---

## 🚀 Project Overview

This project focuses on building an analytics-ready data warehouse using fact and dimension tables.  
The analysis covers:

- Sales Performance Analysis
- Customer Segmentation
- Product Insights
- Change Over Time Analysis
- Cumulative Analysis
- Ranking Analysis
- Part-to-Whole Analysis
- Customer & Product Reporting

The project is designed to simulate real-world business reporting and analytical workflows commonly used in data analyst and business intelligence roles.

---

## 🛠️ Tech Stack

- **Database:** MySQL
- **Language:** SQL
- **Concepts Used:**
  - CTEs (Common Table Expressions)
  - Window Functions
  - Aggregations
  - Views
  - CASE Statements
  - Date Functions
  - Ranking Functions
  - Data Segmentation
  - Analytical Reporting
